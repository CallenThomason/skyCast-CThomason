SkyCast: Build a Weather App
With this project I used everything I learned about javascript, tailwind, and html from the last 4 weeks to build a function weather website. I had a lot of fun creating a changing background using if statement and .includes to group a bunch of the descriptions together. I also found it really satisfying to create cards using a foreach loop in js, instead of making each card seperatly in html with tailwind. Saved a whole lot of time, even though I had all the cards made at first, i didn't have to create a bunch of seperate ids and assign them seperate values.
